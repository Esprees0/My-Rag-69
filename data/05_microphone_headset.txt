หัวข้อ: การแก้ปัญหาไมโครโฟนและ Headset ใน Windows 11

อาการที่พบบ่อย
- Windows ไม่พบไมโครโฟน
- พบไมโครโฟนแต่บันทึกเสียงไม่ได้
- เสียงไมโครโฟนเบามาก
- แอปประชุมออนไลน์ใช้ไมโครโฟนผิดตัว

การเลือกอุปกรณ์ Input
ไปที่ Settings > System > Sound จากส่วน Input ให้เลือกไมโครโฟนหรือ Headset ที่ต้องการใช้ หากมีหลายอุปกรณ์ ควรตรวจชื่ออุปกรณ์ให้ตรงกับตัวจริง

การทดสอบไมโครโฟน
ในหน้าคุณสมบัติของอุปกรณ์ Input สามารถเริ่มการทดสอบและพูดใส่ไมโครโฟน จากนั้นหยุดการทดสอบและเล่นตัวอย่างเพื่อฟังว่า Windows รับเสียงได้หรือไม่ วิธีนี้ช่วยแยกปัญหาระหว่างตัวไมโครโฟนกับปัญหาในแอป

สิ่งที่ควรตรวจเพิ่ม
1) ตรวจว่า Headset เสียบแน่นและใช้พอร์ตที่ถูกต้อง
2) ตรวจว่าไมโครโฟนไม่ได้ถูก Mute จากตัวอุปกรณ์
3) ตรวจสิทธิ์ Microphone สำหรับแอปที่ต้องการใช้งาน
4) ตรวจ Driver ของอุปกรณ์ใน Device Manager
5) ลองใช้ไมโครโฟนอีกตัวเพื่อแยกปัญหาที่ Hardware
6) ใช้เครื่องมือแก้ไขปัญหาเสียงของ Windows หากจำเป็น

กรณีแอปประชุมไม่ได้ยินเสียง
แม้ Windows จะตรวจพบไมโครโฟน แต่แอป เช่น โปรแกรมประชุมหรือแชต อาจเลือก Input Device คนละตัว จึงต้องเข้า Settings ของแอปและเลือกไมโครโฟนตัวเดียวกับที่ตั้งไว้ใน Windows

คำถามที่ระบบตอบได้
- Windows ไม่เจอไมค์ต้องทำอย่างไร?
- จะทดสอบไมโครโฟนใน Windows 11 ได้อย่างไร?
- เสียบ Headset แล้วไมค์ไม่ทำงานต้องตรวจอะไร?
