หัวข้อ: การตรวจสอบและเพิ่มพื้นที่ว่างใน Windows 11

อาการที่พบบ่อย
- ไดรฟ์ C ใกล้เต็ม
- ติดตั้ง Windows Update ไม่ได้เพราะพื้นที่ไม่พอ
- เครื่องทำงานช้าหรือมีปัญหาเมื่อพื้นที่จัดเก็บเหลือน้อย

ตรวจสอบพื้นที่ว่าง
เปิด File Explorer แล้วเลือก This PC เพื่อดูพื้นที่ว่างของไดรฟ์แต่ละตัว หากไดรฟ์หลักมีพื้นที่เหลือน้อย ควรเริ่มจัดการไฟล์ที่ไม่จำเป็นก่อนลบข้อมูลสำคัญ

วิธีเพิ่มพื้นที่ว่าง
1) ลบไฟล์ชั่วคราวที่ไม่จำเป็นผ่าน Settings > System > Storage
2) ตรวจ Recycle Bin และล้างเมื่อแน่ใจว่าไม่ต้องการไฟล์แล้ว
3) ตรวจโฟลเดอร์ Downloads และไฟล์ขนาดใหญ่
4) ย้ายรูป วิดีโอ หรือไฟล์ที่ใช้ไม่บ่อยไปยัง External Drive หรือ Storage ที่เหมาะสม
5) ใช้ Storage Sense เพื่อช่วยจัดการไฟล์ชั่วคราวโดยอัตโนมัติ

Storage Sense
Storage Sense สามารถช่วยเพิ่มพื้นที่โดยอัตโนมัติ เช่น จัดการไฟล์ชั่วคราวและรายการใน Recycle Bin ตามการตั้งค่าของระบบ ผู้ใช้ควรตรวจการตั้งค่าก่อนเปิดใช้งานเพื่อให้เข้าใจว่าไฟล์ใดอาจถูกจัดการ

ข้อควรระวัง
อย่าลบไฟล์ระบบ โฟลเดอร์ที่ไม่ทราบความหมาย หรือไฟล์งานสำคัญเพียงเพราะมีขนาดใหญ่ ควรตรวจชื่อและตำแหน่งไฟล์ก่อนเสมอ และสำรองข้อมูลสำคัญก่อนทำการลบจำนวนมาก

คำถามที่ระบบตอบได้
- เช็กพื้นที่ว่างของไดรฟ์ C อย่างไร?
- จะเพิ่มพื้นที่ใน Windows 11 ได้อย่างไร?
- Storage Sense คืออะไร?
