หัวข้อ: การแก้ปัญหาเมาส์และคีย์บอร์ดใน Windows 11

อาการที่พบบ่อย
- เมาส์ไม่ขยับหรือเคอร์เซอร์ไม่เคลื่อนที่
- คีย์บอร์ดไม่รับปุ่ม
- อุปกรณ์ USB ถูกเสียบแต่ Windows ไม่ตอบสนอง
- อุปกรณ์ไร้สายไม่พบหรือเชื่อมต่อไม่ได้

การตรวจสอบ Hardware
1) ตรวจว่าอุปกรณ์ได้รับไฟและสายเชื่อมต่อแน่น
2) ถอดสาย USB แล้วรอสักครู่ก่อนเสียบกลับเพื่อให้ Windows โหลดอุปกรณ์ใหม่
3) ทดลองพอร์ต USB อื่น
4) หากเป็นอุปกรณ์ไร้สาย ให้ตรวจแบตเตอรี่และการเชื่อมต่อ Bluetooth
5) ทดลองอุปกรณ์กับคอมพิวเตอร์อีกเครื่องเพื่อแยกปัญหา Hardware ออกจาก Windows

กรณีอุปกรณ์ทำงานกับเครื่องอื่นแต่ไม่ทำงานกับเครื่องนี้
ให้ตรวจ Driver และ Windows Update รวมถึงดูอุปกรณ์ใน Device Manager หากมี Error Code ให้จดรหัสก่อนแก้ไข ขั้นตอนนี้ช่วยระบุได้ว่าปัญหาเกิดจากระบบหรือจากตัวอุปกรณ์

ข้อควรระวัง
อุปกรณ์บางรุ่นต้องใช้ Driver เฉพาะ จึงควรดาวน์โหลดจากผู้ผลิตหรือใช้ช่องทางที่เชื่อถือได้ ไม่ควรใช้โปรแกรมอัปเดต Driver ที่ไม่ทราบแหล่งที่มา

คำถามที่ระบบตอบได้
- เมาส์ USB ไม่ทำงานควรทำอย่างไร?
- คีย์บอร์ดไม่ตอบสนองต้องตรวจอะไร?
- จะทดสอบว่าอุปกรณ์เสียหรือ Windows มีปัญหาได้อย่างไร?
